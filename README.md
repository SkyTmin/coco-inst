# Coco Camera 📸

Камера-помощник по композиции для iPhone. Дешёвая альтернатива дорогим приложениям вроде CAMERA GUY.

**Главная фишка** — загрузка собственных портретов-эскизов: выбираете референс из галереи, он накладывается полупрозрачным слоем поверх видоискателя, и вы просто совмещаете человека в кадре с эскизом.

## Возможности (MVP)

- 📷 Видоискатель с фронтальной и основной камерой
- 📐 Сетки композиции: правило третей, золотое сечение, центрирование
- 🖼 Эскиз-портрет: наложение референса из галереи с регулировкой прозрачности
- 💾 Сохранение снимков в галерею

## Стек

- [Expo SDK 57](https://expo.dev) + React Native + TypeScript
- `expo-camera` — видоискатель и съёмка
- `expo-image-picker` — выбор эскиза из галереи
- `expo-media-library` — сохранение снимков

## Запуск для разработки (Mac не нужен)

```bash
npm install
npx expo start
```

Установите приложение **Expo Go** на iPhone и отсканируйте QR-код из терминала — проект откроется на телефоне. Камера и выбор эскиза работают прямо в Expo Go.

## Сборка для App Store (Mac не нужен)

Сборка выполняется в облаке через [EAS Build](https://docs.expo.dev/build/introduction/):

```bash
npm install -g eas-cli
eas login          # аккаунт expo.dev (бесплатный)
eas build:configure
eas build --platform ios       # облачный Mac собирает .ipa, подписи — автоматически
eas submit --platform ios      # отправка в App Store Connect
```

Требования:

1. **Apple Developer Program** — $99/год, регистрация на [developer.apple.com](https://developer.apple.com).
2. Аккаунт [expo.dev](https://expo.dev) — бесплатного тарифа хватает на старте.

Дальше всё в браузере на [App Store Connect](https://appstoreconnect.apple.com): метаданные, скриншоты, политика конфиденциальности — и на проверку Apple.

## Структура

```
App.tsx                  — корень приложения
src/CameraScreen.tsx     — главный экран: камера, управление, съёмка
src/GridOverlay.tsx      — сетки композиции
src/ReferenceOverlay.tsx — полупрозрачный эскиз-портрет
app.json                 — конфигурация Expo (разрешения iOS, bundle id)
```
